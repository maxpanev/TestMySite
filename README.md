# Тестирование сайта Позитроника.

## Описание проекта

Данный проект представляет собой набор автоматизированных тестов для проверки функциональности и корректности работы формы заявки в поддержку сайта [Позитроника](https://positronica.ru/support/). Тесты реализованы с использованием библиотек Selenium и pytest.

## Цель проекта

Цель проекта — обеспечить автоматическую проверку ключевых сценариев взаимодействия с формой поддержки, выявлять возможные ошибки и обеспечивать стабильную работу сайта при внесении изменений.

Проект помогает ускорить процесс тестирования, повысить его надежность и обеспечить контроль качества пользовательского интерфейса.

---

### Структура проекта

- `tests/` — папка с тестовыми сценариями
  - `data/` — папка с переменными и тестовыми данными, используемыми в тестах
  - `helpers/` — папка с вспомогательными функциями и утилитами для тестирования
- `test_cases/` - папка с тест-кейсами
- `requirements.txt` — файл с зависимостями проекта
- `README.md` — файл с описанием проекта

---

## Используемые технологии
- selenium — для автоматизации взаимодействия с веб-страницей, поиска элементов и выполнения действий.
- pytest — для организации тестов и их автоматического запуска.

## Требования
- Python 3.x
- Библиотеки: selenium, pytest
- Веб-драйвер Chrome (chromedriver).

## Как запускать тесты
1. Установите необходимые зависимости:
```bash
pip install -r requirements.txt
```

2. Убедитесь, что у вас установлен ChromeDriver и он соответствует версии браузера Chrome.

3. Запустите тесты командой:
```bash
pytest -v tests/test-form.py tests/test-fields.py
```

## Примечание
Перед запуском убедитесь, что у вас установлен драйвер Chrome и он доступен в системном PATH.
