### Тест-кейс №12: Проверка обработки валидных номеров телефона

**ID:** TC012  
**Название:** Проверка валидных значений для поля Телефон

### Предварительные условия
- Страница формы загружена
- Поле "Телефон" пустое

### Проверяемые значения:
- `9001234567` — стандартный российский номер.
- `(900)-123-45-67` — номер со скобками и дефисами, скобки и дефисы игнорируются при вводе.
- `900-123-45-67` — номер с дефисами, дефисы игнорируются при вводе.
- `900 123 45 67` — номер с пробелами, пробелы игнорируются при вводе.
- `(900) 123-45-67 ext.89` — номер с дополнительными символами, вводятся только первые 10 цифр, остальные система игнорирует".
- `9001234567891234567` — длинный номер, вводятся только первые 10 цифр, остальные система игнорирует.

### Ожидаемый результат:
- При вводе валидных значений номеров, сообщение об ошибке отсутствует, поле выделяется зеленой рамкой.
