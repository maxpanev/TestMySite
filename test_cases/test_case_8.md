### Тест-кейс №8: Проверка поля номер заказа

**ID:** TC008  
**Название:** Проверка валидации поля номера заказа

### Предварительные условия
- Страница формы загружена
- Поле "Номер заказа" пустое

### Проверяемые значения:
- `1234567890` — стандартный номер.
- `(123)(456)(7890)` — номер со скобками, скобки игнорируются при вводе.
- `123-456-7890` — номер с дефисами, дефисы игнорируются при вводе.
- `123 456 7890` — номер с пробелами, пробелы игнорируются при вводе.
- `1234567890111213141516` — длинный номер, вводятся только первые 10 цифр.
- `1` — минимальная длина номера, принимается, оставшаяся пустота заполняется пробелами
- `12,.3ABC78?9!` — номер с буквенными и специальными символами, все символы кроме цифровых игнорируются при вводе.

### Ожидаемый результат:
- При вводе любых цифровых значений, номер успешно принимается.
- Ввод любых символов, кроме цифровых игнорируется.
