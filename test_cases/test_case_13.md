### Тест-кейс №13: Проверка обработки валидных имен

**ID:** TC013  
**Название:** Проверка валидных значений для поля "Имя"

### Предварительные условия
- Страница формы загружена
- Поле "Имя" пустое

### Проверяемые значения:
- `Иван` — ввод допустимого имени с русскими буквами.
- `Хуберт Блейн` — ввод с пробелами внутри, пробелы игнорируются.
- `ИВАН` — валидное имя в верхнем регистре.
- `Иван4`— цифры автоматически удаляются, ввод валидного имени.
- `Ив@н` — спецсимволы автоматически удаляются, ввод валидного имени.


### Ожидаемый результат:
- При вводе валидных значений имен, сообщение об ошибке отсутствует, поле выделяется зеленой рамкой.
