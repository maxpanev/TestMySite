### Тест-кейс №16: Проверка обработки невалидных номеров телефона

**ID:** TC016  
**Название:** Проверка невалидных значений для поля Телефон

### Предварительные условия
- Страница формы загружена
- Поле "Телефон" пустое


### Проверяемые значения:
- `123456` — короткий номер без кода страны, сообщение "Неверный формат телефона".
- `+7900abc4567` — номер с недопустимыми символами, сообщение "Неверный формат телефона".

### Ожидаемый результат:
- При вводе невалидных номеров, система отображает сообщение об ошибке, указывающее на некорректный формат номера.
