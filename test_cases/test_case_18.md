### Тест-кейс №18: Проверка обработки невалидных сообщений

**ID:** TC018  
**Название:** Проверка невалидных значений для поля "Сообщение"  

### Предварительные условия  
- Страница формы загружена  
- Поле "Сообщение" пустое

### Проверяемые значения
- `Три` - сообщение "Минимально допустимое количество символов: 6. Длина текста сейчас: 3".

### Ожидаемый результат
- При вводе невалидных значений, система отображает сообщение об ошибке, указывающее на
некорректный формат сообщения.
