### Тест-кейс №14: Проверка обработки валидных сообщений

**ID:** TC014  
**Название:** Проверка валидных значений для поля "Сообщение"  

### Предварительные условия  
- Страница формы загружена  
- Поле "Сообщение" пустое  

### Проверяемые положительные значения
- `Привет` — сообщение на границе минимального допустимого количества 6 символов, сообщение принимается.  
- `  Три    ` — сообщение с пробелами в начале и в конце, принимается, пробелы считаются символами.  
- `!@#$%^&*()_-+=[]{}|;:'\",.<>/?`~"` — допустимые спецсимволы, сообщение принимается.  
- `1234567890` — цифровые символы, сообщение принимается. 
- `Hello my friend` — сообщение на другом языке, принимается.
- `Тест с пробелами     внутри     и с переносами\nв новых строках.` — сообщение с пробелами и переносами.   
- `<script>alert('test')</script>` - Ввод html-элементов, сообщение принимается.  


### Ожидаемый результат  
- При вводе валидных значений сообщения, текст об ошибке отсутствует, поле выделяется зеленой рамкой.
