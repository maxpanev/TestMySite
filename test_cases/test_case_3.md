### Тест-кейс 3: Проверка заполнения обязательных полей невалидными значениями

**ID:** TC003  
**Название:** Проверка отправки формы с невалидными данными

### Предварительные условия:  
- Страница формы загружена полностью.  
- Все поля пустые.

### Проверяемые значения:   
1. Найти раздел с формой обратной связи.
2. В поле "Email" ввести: `test@example.c`  
3. В поле "Телефон" ввести: `+7900abc4567`  
4. В поле "Имя" ввести: `Ivan`  
5. В поле "Сообщение" ввести: `Тест`  
6. Поставить галочку напротив "Я ознакомлен и согласен с условиями Политики конфиденциальности"  
7. Нажать кнопку "Отправить".

### Ожидаемый результат:  
- Все поля отображают введённые данные.  
- При заполнении данных невалидными значениями, кнопка "Отправить" становится неактивной, при попытке нажать — ничего не происходит.
