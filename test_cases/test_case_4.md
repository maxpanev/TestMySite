### Тест-кейс 4: Проверка работоспособности ссылки "Претензии по заказам с маркетплейсов"

**ID:** TC004  
**Название:** Проверка перехода по ссылке "Претензии по заказам с маркетплейсов" на странице поддержки

### Предварительные условия:  
- Страница формы открыта в браузере.   

### Проверяемые значения:  
1. Найти на странице ссылку, под категориями обращения, выделенную зелёной рамкой, с названием "Претензии по заказам с маркетплейсов".  
2. Кликнуть по этой ссылке.  
3. Зафиксировать, что браузер перенаправляет на URL: https://positronica.ru/pretenzii-po-zakazam-s-markepleysov/  
4. Проверить, что страница загрузилась полностью и соответствует ожидаемому разделу формы претензий.

### Ожидаемый результат:  
- После клика происходит переход на указанную страницу.  
- URL в адресной строке соответствует https://positronica.ru/pretenzii-po-zakazam-s-markepleysov/  
- Страница содержит правильный раздел формы для подачи претензий по заказам с маркетплейсов.
